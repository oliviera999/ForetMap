### Incident d'environnement (à signaler à l'orchestrateur)

Le shell exporte `DB_NAME=foretmap_test` (et `DB_USER`, `DB_PASS`…) : `dotenv` ne surcharge
pas une variable déjà définie, donc **`npm run db:init` / `db:migrate` / `db:status` sans
préfixe visent `foretmap_test`, pas `foretmap_test_f7`**. La base `foretmap_test_f7` n'existait
pas au démarrage du flux ; mon premier `db:init` (sans préfixe) a tourné sur `foretmap_test`
(initSchema + seed `INSERT IGNORE`, rien de vidé). Depuis : toutes les commandes préfixées
`DB_NAME=foretmap_test_f7 TEST_DB_NAME=foretmap_test_f7`. Les tests (`tests/helpers/setup.js`)
prennent `TEST_DB_NAME`, non exporté, donc bien `foretmap_test_f7` via `.env`.
